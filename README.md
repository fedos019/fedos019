# Turbine Blade Suite

Прототип программного комплекса для работы с эталонными OBJ-моделями турбинных лопаток, инженерными зонами, процедурными дефектами, YOLO-разметкой и экспертными правилами.

## Возможности текущего каркаса

- создание проектной структуры с конфигурациями камеры, освещения, генерации и датасета;
- импорт OBJ и базовый отчет качества mesh;
- хранение зон отдельно от OBJ и проверка уникального владения полигонами;
- процедурная генерация дефектов по диапазонам параметров;
- запись YOLO label-файлов для классов дефектов;
- простая экспертная система на пользовательских правилах;
- CLI-команды `init-project` и `validate-obj`.

## Быстрый старт

```bash
python -m turbine_blade_suite.cli init-project ./demo "Demo Blade" blade-a
python -m turbine_blade_suite.cli validate-obj ./demo/blade.obj
```

Подробная модульная архитектура описана в [`docs/architecture.md`](docs/architecture.md).
